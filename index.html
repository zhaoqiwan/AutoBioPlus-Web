01 · Why AutoBio+

Dexterous manipulation in laboratories is more than object placement.

Automating biological laboratories requires robots to perform dexterous tool interactions under realistic visual conditions while handling dynamic experimental phenomena. AutoBio+ is a simulation benchmark and framework for evaluating these capabilities in realistic biological laboratory environments.

✦

AutoBio+ combines interactive simulated foreground objects, Gaussian-splatting backgrounds reconstructed from real laboratories, and parallel evaluation in one benchmark.

02 · Method overview

A hybrid benchmark for evolving laboratory scenes.

A

Particle visual effects

Lightweight, controllable particles model flames, vapor, and bubbles while remaining decoupled from scene physics.

B

Hybrid rendering

Interactive MuJoCo foregrounds are composited with 3D Gaussian Splatting backgrounds captured from six real laboratory scenes.

C

Parallel simulation

PFSM policies, batched rendering, and decoupled trajectory replay support efficient data generation and model-independent evaluation.

Visual conditions that change while the robot acts.
